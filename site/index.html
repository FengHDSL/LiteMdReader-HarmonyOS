澄心执笔，笺上生光。

「澄」是澄澈透光，「笺」是文人读写的纸笺。 澄笺把沉浸光感材质、卡片化排版与一镜到底的动效放进一个纯粹的 Markdown 书房—— 没有信息流，没有账号，没有云端。图表与公式随包离线渲染，批注与学习卡只存在你自己的设备上。

      02 / 能力

      一页一页，都是读写得顺手的地方

      书架、阅读、写作、复习、AI、外观、数据七组能力，全部在同一台设备上完成。下面的每一条都来自应用当前版本的实际功能清单，可切换查看。

      书架：像整理真的书架

      三页循环滑动——文房、书架、写作日志。封面由程序按文档名哈希绘制，长按可以拖动、合并、换位。

      • 三列封面网格：程序化书封配色，可自定义底色、封面图与是否显示名称
      • 长按拖动归组：拖到另一张封面上合并成文件夹，拖进文件夹格收进去，还能互换位置
      • 文件夹原地展开：面板从图标下方长出来，同伴留在原格、下方的书被推开
      • 封面上的进度：底部细进度条与百分比胶囊，回到书架时数字平滑增长
      • 网格 / 树形双视图与全库搜索：命中上下文，可直达正文位置
      • 底部悬浮胶囊：点击新建文档、长按导入文档，与统计文字同在一颗胶囊里

      阅读：专心读这一篇

      多标签同时开着几篇，左侧目录、右侧批注是两条侧滑抽屉；宽屏两侧常驻，分隔条还能拖宽。

      • 卡片化正文：标题刻度线、列表与任务列表、表格、引用、提示块、脚注、代码高亮全部成卡
      • 离线渲染：mermaid · ECharts · Graphviz · flowchart · markmap · 五线谱 · KaTeX 公式，渲染库随包内联，翻到即见
      • 图表与公式全屏放大：旋转横屏、捏合缩放、± 倍率，可另存浅色底图片
      • 荧光笔与批注：选中即弹胶囊，四种荧光色 + 文字批注 + 手写批注，注释列表点击跳回原文
      • 阅读手感：双指捏合即时调字号、亮度滑条与屏幕常亮、五档主题快捷切换、进度自动记忆
      • 每篇可切读写 / 只读：只读时锁住编辑入口，任务勾选不再写盘

      注释侧栏自带搜索，分类筛选固定在顶部——批注多了也能一眼过滤到学习卡或文字批注。

      写作：写起来不打断

      编辑页与阅读页共用同一套渲染器：点哪段改哪段，改完原地变回渲染态。

      • 分段预览编辑：编辑块下方实时渲染，LaTeX 行内 / 块级公式即时出图
      • 实时自动保存：停顿约 1 秒自动落盘，切换段落自动提交，内容不丢
      • 版本历史：自动快照间隔 1 / 5 / 10 分钟可选，支持差异对比与一键恢复
      • 图库导入图片：复制进沙箱 docs/images/ 并以相对路径引用，阅读页真实加载
      • Markdown 快捷工具条与语法速查表、查找替换、跳转行、大纲重排
      • 内置两篇教程：《Markdown 语法教程》与《澄笺示例 · 全功能演示》，默认只读可解锁

      复习：把划过的内容背下来

      划选文字选「学习卡」，就能在应用内背记——不用注册任何第三方学习服务。

      • 学习卡：实色黄底高亮 + 中文备注，与荧光笔、文字批注数据互不干扰
      • SM-2 记忆曲线：记得 / 模糊 / 忘了三档评分安排下次复习，累计三次「记得」才算掌握
      • 复习统计：每日目标条数、连续签到日历、遗忘曲线分布
      • 背卡语音朗读：用系统语音合成读单词与备注，通勤路上也能过一遍
      • 文房页聚合：今日到期、批注速记、全部待办；写作日志另有字数轨迹与热力图

      AI 助手：接口由你定

      应用不内置模型服务、不收任何费用。模型、地址、密钥全部由你填写，我们不经手任何内容。

      • 双协议多配置：OpenAI 兼容 / Anthropic，多份配置随时切换，思考强度可调
      • 图片与文件附件不限数量与大小，大文件按块读取自动分批发送
      • 生成中可切话题：原话题后台继续生成，完成后书架入口亮起角标
      • 回复里的代码块与图表可全屏放大，与阅读页共用同一套浮层
      • 生成文档：AI 输出可直接落盘为书架文档
      • 对话记录只存本机：接口地址与密钥不离开设备，卸载即消失

      使用外部接口产生的费用由该接口提供方收取；澄笺本身不做中转服务器，也没有任何形式的抽成。

      外观：按你的纸与光来

      沉浸光感材质基于系统 uiMaterial 承载层，深浅色切换整树重建；颜色只做薄染，不压过正文。

      • 五档主题：跟随系统 / 浅色 / 深色 / 羊皮纸 / 护眼绿，纸色两档各带深浅孪生调色板
      • 五款澄笺主题色：澄光 / 宣纸 / 砚青 / 竹影 / 霞笺，也可填自定义色号
      • 卡片沾色与主题色流光，灰体文本深浅两套独立配置
      • 深浅两套壁纸与自定义字体导入（.ttf / .otf）
      • 动效服务空间感：封面一镜到底、文件夹展开、粒子消散；智感握姿让底部工具条贴近持机侧
      • v1.1.5 新增：「沉浸光感」「过渡动画」两个总开关，光感分默认 / 节能两档

      真实调色板（取自应用源码）

      数值来自 theme/DesignTokens.ets 与 theme/ThemeStore.ets，可在下面的界面示意里实际切换看看。

      数据：只属于你

      文档、书架索引、批注、学习卡、进度与外观设置全部存在本机应用沙箱内；应用内没有统计、广告、推送 SDK。

      • 本地备份包（zip）导出 / 导入，导入保持宽松兼容
      • WebDAV 备份与恢复：地址与账号只存本机，可设每 1 / 3 / 7 天自动上传
      • 设置分四类：阅读调整 / 外观设置 / 数据管理 / 探索中心，平板横屏自动分栏
      • 检查更新：一键查询发布页最新版本，发现新版可跳转下载
      • 图片管理：正文引用的网络图片可一键下载另存；缓存清理、内置教程移除与恢复
      • 应用初始化：一键把应用恢复到全新安装的状态

      只有两种权限，只有四类联网

      • INTERNET：加载文档里写了的网络图片、与你自己填写的 WebDAV 服务器通信、把 AI 内容直传你配置的接口、检查更新时读版本号
      • DETECT_GESTURE：识别当前握持手以调整底部工具条位置，设备不支持时自动居中
      • 其余全部离线：阅读、写作、批注、复习、导出不需要网络
      • 卸载即清空：全部本地数据随卸载一并删除
      03 / 场景

      四种常见的一天

      下面是功能组合出来的用法示意，不是用户案例或效果承诺——真实成效取决于你读什么、写什么。

      精读

      一篇外刊读到底

      导入 .md 或从其他应用分享进来，左目录右批注两条抽屉，进度自动记忆。

      • 荧光笔 / 波浪线按「块 + 文本区间」记录，调字号行高不错位
      • 文档内查找与大纲跳转
      • 只读模式锁住编辑入口，放心交给别人看

      背词

      划过的生词第二天再遇

      选中单词点「学习卡」，填一句中文备注，之后按 SM-2 曲线排期出现。

      • 正面原文、翻面看备注，记得 / 模糊 / 忘了三档评分
      • 连续签到日历与今日到期条数
      • 背卡可用系统语音朗读

      写作

      一篇长笔记反复改

      分段预览改哪段看哪段，停顿约 1 秒自动落盘，版本历史随时对比回滚。

      • 公式与图表边写边出图，导出即带渲染结果
      • 图片从图库导入，相对路径引用
      • Front Matter 控制封面显示名、底色与日期

      多端

      手机起步，平板接力

      同一套 UI 在手机、平板与 2in1 上自适应：抽屉变常驻三栏，标签栏可收进悬浮胶囊。

      • 多标签阅读，长按关闭其他 / 全部
      • 桌面 2×2 服务卡片直达继续阅读
      • 备份包或 WebDAV 自己搬数据，不经过任何第三方云

        06 / 本地优先

        数据只到你的设备上为止

        这不是「我们承诺不看你数据」，而是结构上没有能看的东西：没有服务端，没有中转，也没有埋点。

        • 一

          本地优先，不做账号

          没有登录、没有云同步默认项、没有行为分析。备份是可选动作，且只去你自己指定的地方。

        • 二

          材质先于装饰

          界面由系统沉浸光感材质承载，颜色只做薄染；深浅色按「应用深浅 × 系统深浅」双维取材质。

        • 三

          阅读优先的排版

          卡片化留白、可调版心、可导入字体，正文与图表都为长文阅读让路。

        • 四

          学习闭环留在应用里

          划选即学习卡、按记忆曲线排期、签到与统计本地存储，不依赖任何第三方学习服务。

        08 / 问答

        常见问题

        与应用内「功能帮助」的速查条目保持一致。

        需要联网吗？

        阅读、写作、批注、复习、导出都能离线完成。联网只发生在四种情况：文档里显式写了网络图片、WebDAV 备份 / 恢复（含自动备份）、你主动使用 AI 助手（内容直传你配置的接口）、探索中心点「检查更新」。

        AI 助手要怎么用？要付费吗？

        在「设置 → 助手设置」里填入你自己的 API 地址与密钥（OpenAI 兼容或 Anthropic 均可）。应用本身不内置模型服务、不收任何费用；使用外部接口产生的费用由该接口的提供方收取。

        我的对话内容会被收集吗？

        不会。AI 助手把你的输入直传你自己配置的接口，应用不经手、不存储任何对话内容到云端；对话记录只保存在本机沙箱，卸载即消失。

        图表和公式支持到什么程度？

        mermaid、ECharts、Graphviz、flowchart、markmap、PlantUML（含 nwdiag / salt / ditaa）等图表与 KaTeX 数学公式、abc 五线谱，渲染库全部离线内联在安装包内，渲染不产生网络请求。图表会在后台预渲染成图片缓存，翻到即见，导出时也直接复用；AI 回复里的图表同样可以全屏放大。

        能导入已有的 .md 吗？

        可以。书架顶栏的文件夹按钮导入 .md / .markdown / .txt，重名会自动加序号、不覆盖已有文档；也可以把文件直接拖进书架窗口，或从其他应用分享到澄笺。

        学习卡和普通批注有什么区别？

        学习卡是独立的高亮形态（实色黄底 + 必填中文备注），专供复习系统使用；荧光笔、波浪线、文字批注是另一种记录形态，两者数据互不影响。

        我的文档存在哪？怎么备份？

        存在应用沙箱内，卸载会一并删除。重要内容建议定期用「本地备份包」导出，或连接你自己填写的 WebDAV 服务器；也可以开启自动备份间隔（每 1 / 3 / 7 天）。

        桌面卡片怎么添加？

        长按桌面空白处 → 服务卡片 → 澄笺，选择 2×2 卡片即可；卡片展示最近文档与阅读进度，点击直达继续阅读。该卡片自 v1.1.1 起恢复启用。

        怎么知道有没有新版本？

        探索中心点「检查更新」，应用读取发布页上的最新版本号与当前版本比对：有新版本会弹窗并可一键跳转下载页，已是最新则直接提示。
