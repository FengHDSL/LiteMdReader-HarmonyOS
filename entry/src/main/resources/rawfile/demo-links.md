## 故意留几个"还没写"的

下面这些链接指向**还不存在的文档**。图谱会把它们列进「**待补文档**」——
等于一份自动维护的"计划要写但还没写"的清单：

- [[教育心理学笔记]]
- [[教案模板]]
- [[实验记录]]

## 这四个功能怎么测（本文件就是测试素材）

| 功能 | 入口 | 会得到什么 |
| --- | --- | --- |
| **批注汇总** | 书架 → 本文件封面「⋯」→ **批注汇总** | 一处列出本文件的所有标注。⚠️ **批注要自己划**（在阅读页选字划荧光笔 / 写批注），内置文档只读，不会预置标注 |
| **批注汇总导出为文档** | 同上 → **批注汇总导出为文档** | 生成一篇《批注汇总》：按文档分组、每组标题是 `[[文档名]]`（点一下跳回原文）、每条带摘要与批注内容 |
| **复习卡片 · 今日到期** | 同上 → **复习卡片 · 今日到期** | 卡片正面是高亮文本，点卡片翻面看批注，再用「忘了 / 模糊 / 记得」三档推进排期 |
| **知识图谱 · 文档引用关系** | 同上 → **知识图谱 · 文档引用关系** | 生成一篇《知识图谱》：里面有关系图（本文件 → 复习计划 / 化学教学论笔记 / 862 考点清单 / 任务池），并列出「待补文档」（上面那三个还没写的）与「未连接」 |

> 想边改边测：用书架**新建**（或底栏「新建」）→ 选「**复习素材**」模板，
> 新建出来的是**可编辑**文档，可以自由划批注再回头看汇总与卡片。

## 怎么验证

1. 打开书架「⋯ → 知识图谱」→ 会生成一篇《知识图谱》文档；
2. 打开它，看箭头方向：`本页 → 复习计划` 表示本页引用了那篇；
3. 上面那三个"还没写"的，应出现在「待补文档」一节里；
4. 如果你新建一篇叫「教案模板」的文档，再生成一次图谱，它就变成正式节点了。
