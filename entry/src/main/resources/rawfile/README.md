# 澄笺ChengJian · Markdown 语法教程

> 欢迎来到澄笺——一款安静、透光、以本地为先的 Markdown 阅读器。
> 这份教程按「从常用到进阶」的顺序讲解澄笺支持的语法，
> 每一节都可以照着输入、立即看到效果。

---

## 开始之前

| 你想做的事 | 怎么做 |
| --- | --- |
| 读这份教程 | 书架上的内置卡片，点开即读 |
| 写一篇新文档 | 书架顶栏的加号，或内容区的新建卡 |
| 导入 .md 文件 | 书架顶栏的文件夹按钮，或长按新建卡 |
| 修改一篇文档 | 卡片右上角「⋯」菜单 → 编辑（只读文档先切成「可写」） |
| 归组 / 建文件夹 | 长按封面拖到另一张上合并，或拖进已有文件夹格 |
| 做标注 | 阅读时长按文字，弹出胶囊后选择 |

内置文档默认**只读**（防止误改）：在阅读页「更多」面板或书架格子的「选择操作」里切到
「可写」，就能像自建文档一样编辑它；它也可以和别的文档一样长按拖动、收进文件夹或合并成文件夹。

## 一、标题与段落

用 `#` 到 `######` 表示一至六级标题：

```
# 一级标题
## 二级标题
###### 六级标题
```

正文就是普通段落，段落之间空一行。
想在段落内强制换行时，在行尾补两个空格即可。

## 二、强调

- **粗体**：`**文字**` 或 `__文字__`
- *斜体*：`*文字*` 或 `_文字_`
- ***粗斜体***：三个星号套用
- ~~删除线~~：`~~文字~~`
- ==荧光高亮==：`==文字==`（澄笺扩展）
- 上标与下标：`X^2^`、`H~2~O`（澄笺扩展）

## 三、列表

无序列表用 `-`：

- 阅读时保持专注
- 记录稍纵即逝的想法
- 定期回顾批注

有序列表用 `数字.`：

1. 新建文档
2. 输入内容
3. 预览确认

嵌套只需缩进两格。任务列表用方括号：

- [ ] 学会任务列表
- [x] 它会渲染成可勾选的框

## 四、引用与提示块

一行 `>` 开头就是引用：

> 澄，是澄澈透光；笺，是读写的纸笺。

提示块在引用的基础上加标签，适合放提示与警告：

> [!NOTE]
> NOTE 用于补充说明。

> [!WARNING]
> WARNING 用于需要当心的操作。

## 五、代码

行内代码用反引号：`const ok = true`。

代码块用三反引号围栏，标注语言可获得高亮：

```ts
// 澄笺不上传任何数据，进度只存在本机
interface Progress {
  doc: string;
  ratio: number;
}
```

不标注语言也可以，会以等宽字体呈现。

## 六、表格

表头下一行用 `---` 分隔，冒号决定对齐方向：

| 语法 | 对齐 | 用途 |
| :--- | :---: | ---: |
| `:---` | 左 | 普通说明 |
| `:---:` | 中 | 数字列 |
| `---:` | 右 | 金额、进度 |

## 七、链接与脚注

链接写成 `[文字](地址)`：访问[澄笺的项目主页](https://github.com/FengHDSL/LiteMdReader-HarmonyOS)。

脚注用 `[^名字]` 标记，在文末给出定义：

澄笺的每一次批注都留在本机[^note1]，不参与任何统计[^note2]。

[^note1]: 批注按文档分别存储在应用沙箱。
[^note2]: 没有账号系统，也就没有账号泄露的风险。

## 八、更多块级元素

分隔线用三个以上的短横线：

---

折叠细节块，点击标题展开：

<details>
<summary>这段正文在折叠里</summary>

折叠内的文字同样参与渲染，可以放长解释、代码或列表。
</details>

提示：需要表达数学时可用 `$E = mc^2$` 行内公式，
需要图表时可使用 mermaid / markmap / echarts 等围栏块——
完整示例见内置文档「澄笺示例 · 全功能演示」。

## 九、和澄笺配合的几个习惯

1. **长按就是一切**：选中文字后弹出的胶囊承载荧光、批注、复制与清除。
2. **进度自动记录**：退出再进，回到上次的位置。
3. **导出随时可用**：阅读页可导出 HTML，数据管理页可整体备份。

## 十、遇到问题

- 排版异常时，先检查标记两侧是否有空格；
- 表格错位通常是分隔行的短横线数量不够；
- 图表不渲染时确认围栏标注的语言名拼写。

祝你在澄笺读得安静，写得顺畅。
