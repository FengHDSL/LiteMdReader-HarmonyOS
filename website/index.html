架

书架 · 三页分页

文房 · 书架 · 写作日志

AI ASSISTANT

AI 助手：接口由你定夺

澄笺不内置任何模型服务。在设置里填入你自己的 API 地址与密钥—— OpenAI 兼容或 Anthropic 皆可，多份配置随时切换。

发送消息时，你的文本、选中的原文与附件通过系统网络组件直接发送到该接口： 我们不经手、不存储、也无法恢复这些内容；对话记录只保存在本机沙箱。

  • 附件不限量：图片与文件多选，超大文件按块自动分批上传
  • 后台生成：切话题不打断，完成后续接时入口亮起角标
  • 生成文档：AI 输出直接落盘为书架文档
  • 全屏放大：回复中的代码块与图表，与阅读页同一套浮层
对话记录只保存在本机沙箱，卸载即消失；使用外部接口产生的费用由接口提供方收取。

一次真实的使用流

把《经济学人》里不会的词划成学习卡 → 让 AI 为每个词生成释义与例句并写成一篇「词汇笔记」 落到书架 → 第二天在复习卡片里按记忆曲线背记 → 忘了的词让 AI 再出十道例句。

从阅读到复习，一条流水线，全程离线留存。

FAQ

常见问题

需要联网吗？

阅读、写作、批注、复习、导出全部离线可用。联网只发生在四种情况：文档里的网络图片、 WebDAV 备份 / 恢复（含自动备份）、你主动使用 AI 助手（内容直传你配置的接口）、检查更新。

AI 助手要付费吗？数据安全吗？

应用不内置模型服务、不收任何费用。接口地址与密钥由你自己填写，对话内容直传该接口， 澄笺不经手、不存储；对话记录仅保存在本机沙箱，卸载即消失。

附件有大小和数量限制吗？

不限制。图片与文件均可多选；超大文件按块从磁盘读取、自动分批发送，偏大时应用会提醒。

学习卡和普通批注有什么区别？

学习卡是独立的高亮形态（实色黄底 + 必填中文备注），专供复习系统；荧光笔、波浪线与 文字批注是另一种记录形态，数据互不影响。

我的文档存在哪？

应用沙箱内，卸载即删除。建议定期导出本地备份包，或配置 WebDAV 自动备份 （每 1 / 3 / 7 天）。

桌面卡片怎么添加？

长按桌面空白处 → 服务卡片 → 澄笺，选择 2×2 卡片即可；卡片展示最近文档与阅读进度， 点击直达。
